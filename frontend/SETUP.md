# Quick Setup Guide

## Getting Started

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the application:
   ```bash
   npm run dev
   ```

## Default Login Credentials

**First Time Login:**
- **Username:** `admin`
- **Email:** `admin@geofencealert.com`
- **Password:** `Admin@123`

## Important Notes

1. **Change Password Immediately:** After first login, you MUST change your password
2. **Admin Only Access:** Only users with "admin" role can access the desktop application
3. **Automatic Setup:** The app creates these default credentials automatically on first launch

## After First Login

1. You'll see a password change dialog
2. Create a strong password with:
   - Minimum 8 characters
   - At least one uppercase letter
   - At least one lowercase letter
   - At least one number
   - At least one special character

## Creating Additional Admin Users

1. After logging in, go to "Users" page
2. Click "Invite User" button
3. Fill in user details and select "Administrator" role
4. Save and share the generated credentials securely
5. New users must also change their password on first login

## Security Reminder

⚠️ **Never share or use the default credentials in production!**
- Change the default password immediately
- Invite real users with proper credentials
- Only give admin access to trusted personnel
